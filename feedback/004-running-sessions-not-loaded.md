# 004 설치 전에 열려 있던 세션엔 스킬·CLAUDE.md 블록이 안 들어감

```yaml
상태: 반영 (main 5e4f7dc)
날짜: 2026-10-31
출처: 집 PC. 설치 직후 사용자 질문 "다른 세션에서 lotto-lab 하고 있었는데, 그 세션에서 kb-harvest 쓰면 돼?"
대상: SETUP.md:158 ("새로 시작하세요")
심각도: 중 — 사용자는 진행 중인 작업 세션을 버리고 새로 열 수 없음 (대화 내용이 그 세션에만 있음)
```

## 증상

- 4장은 "새로 시작하세요" 만 안내한다
- 실제 사용자는 설치하는 동안 다른 세션에서 작업 중이었고, 그 세션의 대화를 kb 에 남기고 싶어 했다. 새 세션을 열면 남길 대화가 없다
- 설치 전에 시작한 세션은 스킬 목록·CLAUDE.md 블록·hook 을 모를 수 있다 [확인필요: Claude Code 가 세션 도중 스킬을 다시 읽는지는 버전마다 다를 수 있음. 이번 세션에선 설치 후 스킬 목록이 갱신되어 보였다]

## 이번에 안내한 것

- 그 세션에서 `/kb-harvest` 를 먼저 쳐 보고, 없으면 "`{CONFIG}/skills/kb-harvest/SKILL.md` 읽고 그대로 따라서 이 대화 kb 에 반영해줘" 라고 말하기

## 제안

- 4장 보고 템플릿 「이제 이렇게 쓰세요」 에 한 줄 추가: "설치 전에 열려 있던 세션은 스킬이 안 보일 수 있어요. 그 세션에서는 `{CONFIG}/skills/{이름}/SKILL.md 읽고 따라 해줘` 라고 하면 돼요"
- 1장 시작 전에 "지금 다른 세션에서 하던 작업이 있나요?" 를 물을 필요는 없음 (안내 한 줄로 충분)
