# /compact-confirm — compact 전 점검 + 이어하기·이력 남기기

compact 하면 대화의 세부가 요약으로 줄어든다. 그때 사라지면 안 되는 것은 **파일에 있어야** 다음 세션(또는 compact 뒤의 나)이 이어받는다. 이 스킬은 "대화에만 있는 것"을 찾아 파일로 옮기고, 남은 위험을 표로 보여 준 뒤 compact 해도 되는지 판정한다.

> 경로: `{KB}`·`{TASKS}`·`{MEMORY}` 의 실제 위치는 CLAUDE.md 「keep-ai-brain 경로」 표를 따른다.

## 지킬 것

```yaml
창작_금지: 이번 대화에서 실제로 한 것·확인한 것·사용자가 말한 것만 적는다. 추정은 "추정" 이라고 쓴다
커밋_안함: git add/commit/push 는 하지 않는다 — 커밋 안 된 것을 보고하고, 사용자가 "커밋해줘" 하면 그때
덮어쓰기와_쌓기: 이어하기.md = 지금 상태만, 덮어쓴다(낡은 줄은 고쳐 쓰고 지운다). 이력.md = 경위를 쌓는다, 기존 내용은 고치지 않는다
이력_위치: 이력.md 머리말·기존 모양을 따른다 — "새로운 것이 위" 면 머리말 바로 아래, 아니면 끝에
비밀값: 비밀번호·토큰·키는 문서에 적지 않는다 (명령에 섞여 있으면 <PASSWORD> 등으로)
보고: 짧게, 표 위주. 사용자가 할 일은 번호를 매겨 맨 끝에
```

왜 둘로 나누나: 이어하기에 경위까지 쌓으면 금방 길어져 다음 세션이 "지금 무엇을 하면 되나" 를 찾지 못한다. 지금 상태(덮어쓰기)와 경위(쌓기)를 나누면 이어하기는 늘 짧다.

## 절차

### 1. 이번 세션이 손댄 곳 찾기

대화를 처음부터 훑어 아래를 목록으로 만든다. 한 세션에서 작업 폴더가 둘 이상일 수 있다.

| 종류 | 찾는 법 |
|---|---|
| 작업 폴더 | `{TASKS}/{yyMMddHHmmss}{이름}/` — 이어하기.md·이력.md 가 있는 곳. 대화에서 읽거나 쓴 경로 |
| git 저장소 | 고친 파일이 속한 저장소 — 프로젝트 저장소, `{KB}` 등. 작업 폴더는 메모를 두는 곳이라 보통 git 이 아니다 (그 안에 따로 만든 저장소가 있으면 그것도) |
| kb·메모리 | `{KB}` 를 고쳤는지, 메모리(`{MEMORY}`)를 고쳤는지 |
| 띄운 것 | 로컬 서버, 백그라운드 명령 |
| 대화에만 있는 것 | 사용자가 전한 결정·방침, 받은 메시지(붙여 넣은 글), 사용자가 붙여 준 출력 |

### 2. 점검하고, 고칠 수 있는 것은 고친다

각 항목을 **OK / 고침 / 사용자 할 일** 중 하나로 판정한다.

**A. 이어하기·이력** (가장 중요)
- 폴더마다 이어하기.md 를 읽고, 이번 세션에서 바뀐 것(끝난 일, 새 결정, 다음 할 일, 마지막 커밋, 주의할 점)이 반영됐는지 본다. 빠졌으면 고쳐 쓴다 — 머리말의 기준 날짜도 오늘로
- 「해봤는데 안 된 것」 절에 이번 세션에서 시도했다가 버린 방법을 더한다 — 한 줄에 하나, `{방법} → 안 됨: {이유 한 줄}` (자세한 경위는 이력.md). 다음 세션이 같은 길을 다시 가지 않게 하려는 것이다. 이제 되는 것·다시 해볼 만해진 것은 지운다
- 이력.md 에 이번 세션 경위를 한 덩어리로 더한다: 날짜, 받은 메시지·사용자 결정(누가·무엇을), 한 것, 시행착오(무엇이 왜 틀렸고 어떻게 고쳤나), 근거 파일 위치
- 이어하기.md 가 없는 폴더에서 일을 꽤 했다면 짧게 새로 만든다 (0. 금지·주의 / 1. 지금 상태 / 해봤는데 안 된 것 / 2. 다음 할 일 / 3. 지키는 결정 / 4. 파일·실행 방법)
- 일이 끝났으면 머리말에 `상태: 완료` 를 적는다 (작업 폴더 점검기가 이 줄로 끝난 일을 구분한다)

**B. 커밋 안 된 것**
- **이번 세션에 파일을 고친** 저장소마다 `git status --short`. 읽기만 한 저장소는 건너뛴다
- 내가 만든 변경인지, 다른 세션 것인지 구분해 보고한다 (`git log` 최근 몇 개로 다른 세션 커밋도 알아본다)
- kb 에 `[확인필요]` 를 새로 넣었으면 `node {KB}/_tools/collect-questions.cjs` 로 질문 목록을 다시 모은다
- 커밋은 하지 않는다 — "커밋 안 된 것" 으로 표에 올린다

**C. 덮어써질 근거 출력**
- 사용자가 임시 파일(temp.txt 등)에 붙여 준 출력을 근거로 문서에 무언가를 적었다면, 그 출력이 아직 남아 있는지 본다. 남아 있으면 작업 폴더에 이름을 붙여 복사해 두고(`{주제}_{YYMMDD}_{n}차.txt`) 문서의 근거 경로를 그 파일로 바꾼다. 이미 덮어써졌으면 "원문 없음, 핵심 줄은 문서에 인용" 으로 적는다

**D. 대화에만 있는 결정·사실**
- 사용자 결정, 받은 메시지의 방침, 사람에 대한 정보(역할·선호)가 파일 어디에도 없으면 옮긴다: 작업에 묶인 것 → 이어하기 「지키는 결정」·이력, 여러 작업에 걸치는 것 → 메모리(기존 메모리를 먼저 찾아 고치고, 없을 때만 새로 — 목차 한 줄도)

**E. 띄운 것**
- 내가 띄운 서버·백그라운드 작업이 남아 있으면 끈다. 끄기 전에 **주소까지** 확인해 내가 띄운 것만 끈다 — 같은 포트에 사용자가 띄운 서버가 있을 수 있다

**F. 파일 상태**
- 스크립트로 고친 md 가 CRLF 로 바뀌지 않았는지 본다 (Windows 에서 파이썬 `write_text` 등은 `\n` 을 CRLF 로 바꿔 쓴다 → kb 는 frontmatter 검사에 걸린다). CRLF 면 LF 로 되돌린다
- 고친 경로 문자열에 백슬래시가 깨지지 않았는지 (Windows 경로가 탭·줄바꿈으로 바뀌지 않았는지) 검색으로 본다

**G. 멈춘 일**
- 반쯤 한 편집, 머지 도중, 사용자 답을 기다리는 질문이 있으면 이어하기 「다음 할 일」 맨 위에 적는다

**H. kb 후보**
- 대화에 kb 에 남길 사실(코드·DB 로 확인한 동작, 이슈, 사고, 실측, 해소된 `[확인필요]`, 대화 중 바로잡은 사실)이 있는데 kb 를 안 고쳤으면 표에 "kb 후보 있음 → /kb-harvest" 로 올리고, 보고 끝에 "kb 에 남길 게 있어요({주제}). 이어서 /kb-harvest 할까요?" 라고 묻는다. 사용자가 예 하면 kb-harvest 를 이어서 한다. 이 스킬이 kb 를 직접 쓰지는 않는다 — 고르는 기준은 kb-harvest 가 정본

| 둘의 차이 | 남기는 것 | 어디에 |
|---|---|---|
| compact-confirm (이 스킬) | **이 일**의 지금 상태·다음 할 일·경위 | `{TASKS}/{작업}/이어하기.md`·`이력.md` |
| kb-harvest | **다른 일에도** 다시 쓸 사실 — 확인한 동작·함정·바로잡은 사실 | `{KB}` |

### 3. 판정과 보고

```markdown
**compact 해도 됩니다.** (또는: **아래 N가지만 하고 compact 하세요.**)

| 점검 | 결과 |
|---|---|
| 이어하기·이력 | {폴더}: 고침 — {무엇을} (안 된 것 n줄 추가) |
| 커밋 안 된 것 | 없음 / {저장소}: {파일 n개} (커밋은 "커밋해줘" 때) |
| 근거 출력 | OK / {파일} 로 보관 |
| 대화에만 있던 것 | OK / 메모리 {이름}·이어하기에 옮김 |
| kb 후보 | 없음 / 반영됨 / 있음 → /kb-harvest ({주제}) |
| 띄운 것 | 없음 / {포트} 끔 |
| 파일 상태 | OK / {파일} CRLF → LF |

**이어 갈 때**: "{폴더 이름} 이어하기 읽고 {다음 할 일}" 이라고 하시면 됩니다.

사용자가 할 일: (있을 때만)
1. …

(kb 후보가 있을 때만) kb 에 남길 게 있어요 — {주제}. 이어서 /kb-harvest 할까요?
```

- 커밋 안 된 것이 남아 있어도 파일에 다 있으면 compact 는 해도 된다 (커밋은 compact 와 무관). 단, 그 사실은 표에 남긴다
- "해도 됩니다" 는 A·C·D 가 모두 OK 거나 고침일 때만. 사용자 결정이 필요한 것이 있으면 "이것만 정해 주세요" 로

## Windows 에서

- 여러 줄 수정은 파일 편집 도구, 또는 파일로 만든 스크립트(`newline="\n"` 으로 쓰기). **Bash heredoc 안에 Windows 경로(백슬래시)나 정규식을 넣지 않는다** — `\\` 가 줄고 `\t` 가 탭이 된다
- 자세한 함정은 keep-ai-brain `docs/windows-pitfalls.md`
